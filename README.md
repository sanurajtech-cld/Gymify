# Health & Fitness Planner

A health and fitness application designed to help users plan, track, and maintain their exercise routines based on their age, weight, fitness goals, and workout preferences. The application provides a comprehensive collection of exercises for both home and gym workouts, along with alarm and reminder functionality to support consistent fitness habits.

### Key Features
- **Exercise Library:** A collection of exercises with details to help users follow their workout routines.
- **Personalized Workout Plans:** Plan exercises based on age, weight, fitness goals, and workout preferences.
- **Home & Gym Workouts:** Create workout routines tailored to available equipment and workout locations.
- **Alarm & Reminders:** Schedule exercise alarms and reminders to maintain a consistent workout schedule.
- **JWT-Based Authentication:** Secure API endpoints using JSON Web Tokens (JWT) for authentication and authorization.
- **Health & Fitness Management:** Organize daily exercise routines and build sustainable fitness habits.

### Objective
To provide a convenient, secure, and personalized platform that makes fitness planning accessible, whether users prefer exercising at home or in a gym.
